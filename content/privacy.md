GBAK является информационным сайтом, предназначенным для публикации профессиональных материалов. Сайт не предусматривает регистрацию пользователей, создание личных кабинетов или отправку персональных данных через формы.

## Сбор данных

GBAK не использует системы веб-аналитики, рекламные трекеры и другие инструменты отслеживания посетителей. Сайт не устанавливает собственные файлы cookie и не ведёт учёт посещений или действий пользователей.

## Техническая инфраструктура

Сайт размещён на платформе GitHub Pages. При обращении к сайту инфраструктура GitHub может автоматически обрабатывать технические сведения, необходимые для предоставления доступа к страницам, включая IP-адреса и информацию о браузере.

Обработка таких сведений регулируется [политикой конфиденциальности GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Внешние ссылки

Материалы GBAK могут содержать ссылки на сторонние сайты. При переходе по ним обработка данных осуществляется в соответствии с правилами соответствующих ресурсов.
